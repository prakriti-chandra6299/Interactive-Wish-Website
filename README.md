# Wishes 💌
### A little joy, wrapped in a message.

Wishes is an interactive greeting website that turns a simple message into a delightful experience. Users can personalize their wishes, choose a cute cartoon companion, answer fun questions, and reveal a heartfelt message at the end.

## ✨ Features

- **Personalized Greetings** — Create messages with sender and receiver names.
- **Cartoon Companions** — Choose a character for the adventure.
- **Interactive Quiz** — Enjoy fun, multiple-choice questions.
- **Surprise Reveal** — Uncover a personal message at the end.
- **Shareable Wishes** — Generate links containing personalized wish details.
- **Responsive Design** — Enjoy a colorful interface across screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/wishes.git
   ```

2. Open the project folder.
3. Launch `index.html` in your browser.
4. Create a wish and explore the experience.

No additional installation is required.
